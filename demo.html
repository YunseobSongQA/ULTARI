심사·시연용

파일 없이 결과 화면을 봅니다

견본을 고르면 검증을 마쳤을 때 나오는 화면이 그대로 나옵니다. 따로 가입하거나 파일을 준비하실 필요가 없습니다.

이 페이지의 측정값은 파일을 잰 값이 아닙니다. 실제 측정에서 나오는 범위에 맞춰 미리 적어 둔 견본입니다. 다만 등급과 판정 근거는 지어내지 않았습니다 — 그 견본 값을 실제 판정 코드에 그대로 넣어 받은 결과입니다. 진짜 파일을 재는 것은 검증 화면에서 하시면 됩니다.

직접 돌려 보시려면

검증 화면에서 사진·영상·음악 아무 파일이나 고르시면 됩니다. 계정도 결제도 없습니다.

간단 검사는 파일을 어디로도 보내지 않습니다. 측정은 전부 브라우저 안에서 일어납니다. 개발자 도구의 네트워크 탭을 켜 두고 검사를 돌려 보시면 요청이 한 건도 나가지 않는 것을 보실 수 있습니다. 네트워크를 쓰는 코드는 상세 검사 신청 버튼 뒤에만 있습니다.

카메라에서 바로 꺼낸 원본이 아니면 대개 판정 불가가 나옵니다. 메신저를 한 번만 거쳐도 촬영 정보가 통째로 지워지기 때문입니다. 그것도 이 서비스가 하는 말 중 하나라, 위 견본에 같이 넣어 두었습니다.

접수 뒤에는 이렇게 보입니다

상세 검사를 신청하시면 접수번호가 나오고, 연락처와 비밀번호로 현황을 여실 수 있습니다. 아래는 그 화면의 견본입니다 — 접수번호도 견본이라 실제로 조회되지 않습니다.

이 데모가 보여 주지 않는 것

  • 인증 마크 새기기 — 원본 사진이 있어야 새길 수 있어 견본에서는 뺐습니다. 실제 화면에서는 3등급이 나온 자리에 바로 붙습니다.
  • 상세 검사 접수 — 누르면 원본 파일이 서버로 올라갑니다. 견본으로 접수 건수를 늘리지 않기 위해 이 페이지에서는 떼어 냈습니다.
  • 1·2등급 발급 — 사람이 직접 보는 등급이라 며칠에서 몇 주가 걸립니다. 화면에서 즉시 나오는 것은 3등급까지입니다.

대기 건수와 아카이브 보관 건수는 견본에도 넣지 않았습니다. 그 숫자는 실제 접수 건수에서만 표시합니다.
