지금 되는 것

2026년 9월에 영상과 음악·소리를 더했습니다. 실제 파일 스물한 개(아이폰 MOV, 메신저를 거친 영상, 화면 녹화, 통화 녹음, 음원)로 재서 임계값을 정하고, 검출되지 않는 기준은 지웠습니다. 무엇을 지웠는지는 검증 원리와 한계에 적어 두었습니다.

간단 검사
브라우저 안에서 촬영 흔적 여섯 가지를 재고 3등급을 발급합니다. 30초.
인증 마크
3등급을 받은 사진에 마크와 원본 지문을 새겨 내려받습니다.
상세 검사 접수
측정 결과를 신청서로 만들어 사람 심사로 넘깁니다.
측정값 전면 공개
무엇을 쟀고 얼마가 나왔는지 전부 화면에 적습니다.

만들고 있는 것

2등급 심사 운영
사람이 보는 절차를 실제로 돌립니다. 화면 재촬영 판별 기준을 문서로 정리하는 중입니다.
센서 지문 대조
같은 카메라에서 나온 사진들의 화소 불균일 패턴을 맞춰 봅니다. 1등급의 핵심입니다.
영상 지원
지금은 사진만 됩니다. 영상은 프레임 단위로 같은 측정을 할 수 있지만 계산량이 다릅니다.
여러 장 한 번에
한 세션에서 여러 파일을 이어서 검증하고 결과를 묶어 내려받기.

검토 중

오리지널 아카이브
원본을 맡아 두고 B2B 판매 시 수익을 나누는 구조. 접수만 받고 있습니다. 자세히
RAW 지원
브라우저가 RAW를 디코딩하지 못합니다. 간단 검사를 브라우저 안에 두면서 푸는 방법을 찾는 중입니다.
인증 페이지
지문으로 등급을 조회하는 공개 주소. 서버가 필요해 보류 중입니다.

하지 않을 것

몇 가지는 아예 안 하기로 정해 두었습니다. 요청이 들어와도 안 합니다.

  • AI 이미지 탐지 — 생성 모델을 쫓아가는 방식은 구조적으로 지는 게임입니다. 흔적이 남았는지만 봅니다.
  • AI 학습 차단 — 막을 방법이 없습니다. 있다고 파는 것은 거짓말입니다.
  • 정확도 숫자 — 정답이 붙은 표본을 모으는 일 자체가 이 서비스가 풀려는 문제와 같습니다. 만들 수 없는 숫자는 적지 않습니다.
  • 대기열 부풀리기 — 심사 대기 건수는 실제 접수 건수입니다. 0건이면 0건이라고 씁니다.

자동 검증이 놓치는 경우는 한계 페이지에 따로 정리해 두었습니다.
